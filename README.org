* 使用CMake
** 终端命令
*** 构建项目
1) cmake -B build -DCMAKE_BUILD_TYPE=Debug
2) cd build
3) cmake --build .
*** ctest测试
ctest -C Debug

* 测试
** 测试文件命名方式
目前test目录下是问题目录，
问题目录下有problem_input、problem_output和reference_output
以problem_input下的txt文件为输入，程序输出和reference_output做比较，
输入文件名为xxx-input.txt，参考输出文件名为xxx-output-ref.txt。
